      How a choice is made

      1. Score. The twin model rates each option 0–10 per principle.
      2. Weigh. Weighted value = Σ weight × score ÷ 10.
      3. Veto. Hard-rule breaks, or a score under a veto line, drop to 0%.
      4. Probabilities. Values become percentages (softmax).
      5. Model's own view. With open weights we also read the model's token probability for each option letter, where it writes its answer after reasoning.
      6. Blend and answer. 70% principles + 30% model; the top option goes back to the builder. Close calls are flagged.
